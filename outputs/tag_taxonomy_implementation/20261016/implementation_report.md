## 採用した検索仕様

- 正規名「ロールリバーサル」と「デイロールリバーサル」「でいろーるりばーさる」は確定別名グループです。時間足・成立条件・売買条件の同一性は意味しません。
- 「BB COMP」と辞書別名「BBコンプ」「BBコンプレッション」は同じ検索グループです。
- 複数タグは初期AND、ORへ切替可能です。別名は常に同じタググループです。
- 「複合表記を含める」は初期OFFです。場面の元タグと複合ルールの表記が完全一致した場面だけを展開します。フリーテキストの部分一致では付与しません。
- `SR_flip`は独立タグのまま「ロールリバーサル」の関連候補として、`range`は独立タグのまま「BB COMP」の関連候補として、選択時のみ追加します。親子タグは新設していません。
- 日付・本文／ID・銘柄・実行区分・時間足・分類元は同じsceneカード上でAND条件になります。タグ本文検索とタグ選択は別です。`銘柄未確認`と`複数銘柄／集約記録`も別フィルターです。
- 既存の`?tag=`、`?q=`、`?symbol=`、`?execution=`、`?source=`、`?diary_id=`、`?case_id=`を保ち、複数tag・AND/OR・複合・関連・時間足をURLに保存する実装にしました。戻る／進むの動作はブラウザー未確認です。
- 日誌から`diary_tag_index.html?tag=...`へ戻るリンクを持つ既存ローカルコピー用に、クエリとフラグメントを保持して作業ルートの索引へ転送するローカルブリッジを追加しました。
