# タグ定義・取り組み方台帳

この台帳は、各タグの検索上の意味と、本人が決めた取り組み方を分けて記録します。未確認の意味・条件・数値・損益は補わず、空欄または「未確定」とします。

- [全タグの定義・取り組み方一覧](index.html)：現行索引タグすべてを検索し、タグから場面一覧へ戻れます。
- [共通ひな型](TAG_DEFINITION_TEMPLATE.md)：タグ別定義を追記するときに使います。
- [ロールリバーサル](role_reversal.md)：本人確定の別名グループと、複合表記検索の扱い。
- [BB COMP](bb_comp.md)：BB COMP事例、計測項目、未確認値。
- [Astra 6.1への質問案](QUESTIONS_FOR_ASTRA_6_1.md)：類似語・検索設計の検討資料。
- [分類調査の証拠一覧](../outputs/tag_taxonomy_research/20261016/evidence_report.md)：元資料探索の方法と件数。
- [今回のローカル実装・検証結果](../outputs/tag_taxonomy_implementation/20261016/implementation_report.md)：今回の採用仕様、動作確認、保留点。

## いまの検索分類

- 「デイロールリバーサル」「でいろーるりばーさる」は、本人指定の正規名「ロールリバーサル」の確定別名です。これは検索上の同一グループであり、時間足・成立条件・売買ルールの一致を意味しません。
- 「BBコンプ」「BBコンプレッション」は、辞書登録済みの「BB COMP」別名です。約600円は2026-08-12のJP225・1時間足の一事例です。
- VWAP／サポレジを含む複合表記や「ロールリバーサル失敗」「BBコンプ下降トレンド」は、原文表記を保った複合検索です。別名と同じ扱いにせず、「複合表記を含める」を選んだ場合に、同じ場面のタグが完全一致したものだけを検索します。
- `SR_flip` と `range` は別タグです。ロールリバーサル、BB COMPとの関係は、利用者が索引で関連候補を選んだ場合だけ検索へ追加します。自動統合・親子関係はありません。
- 複数タグは初期状態でAND。確定別名はタググループ内で常にまとめて検索します。

## 定義を書き足す場所

1. [全タグ定義レジストリ](../data/diary_tag_definitions.json)を開き、正規タグに一致する`tags`要素の`approach`欄を編集します。
2. 既存の日誌タグ・scene/case ID・タグ辞書は変更せず、意味・条件には必ず出典または本人確認の根拠を添えます。
3. 未確定条件は空欄のままにします。失敗・損益・候補の区分を、別の情報から推測しません。
4. 一覧を再生成するときは作業ルートで `python3 scripts/tag_taxonomy_support.py` を実行します。既存の手入力`approach`欄は生成スクリプトが保持します。
5. 場面検索索引を再生成するときは `python3 scripts/diary_tag_catalog.py` を実行します。検索仕様は `data/diary_tag_taxonomy.json` と `data/diary_scene_annotations.json` にあります。

## 区分の記録

次を別の属性として扱います。ひとつの場面が本人振り返りとPaper取引の両方を含むことがあります。

- 記録の性質：本人振り返り、候補、観察、実況など。
- 口座環境：実口座、Paper、DEMO、未確認。
- 行動：未発注、注文、未約定、取消、約定など。
- パターン結果：原文にある結果表示、判定対象、未知事項。
- 執行評価：飛び乗り等の反省。損益やパターン結果と混同しない。
- 損益：口座環境、通貨、出典、照合状態。Paperや未実行候補の損益は実口座損益へ加えない。

タグと銘柄の照合は同じ場面レコードで行います。場面の主対象と環境参照を分け、同日という理由だけで別場面を結びません。
